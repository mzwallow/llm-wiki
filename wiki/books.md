# Books

Reference list of foundational computer science, software engineering, and mathematics literature.

## Operating Systems
- **OSTEP (Operating Systems: Three Easy Pieces)** by Remzi H. Arpaci-Dusseau and Andrea C. Arpaci-Dusseau.
  - Covers virtualization, concurrency, and persistence.
  - Link: [OSTEP](https://pages.cs.wisc.edu/~remzi/OSTEP/)

## Game Programming
- **Game Programming Patterns** by Robert Nystrom.
  - Architecture patterns for game development and software engineering.
  - Link: [Game Programming Patterns](https://gameprogrammingpatterns.com)

## Mathematics
- **Linear Algebra Done Right** by Sheldon Axler.
  - Proof-based linear algebra emphasizing linear maps over matrices.
  - Link: [Linear Algebra Done Right](https://linear.axler.net/)
